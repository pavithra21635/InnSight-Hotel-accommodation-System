
## Description
Hotel accommodation System that handles employee , customers, rooms, reservation, and inventories, reports.
Minimize operational inefficiencies.

## Features
Login & Authentication
Employee, Room, Customer & Inventory Management
Reservation System
Report generation


## Installation & Setup
1. Clone the repository
2. Install dependencies
1. Change the datasouce name to your server name in the connection string in connection.cs file
3. Run the project
